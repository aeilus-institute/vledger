## Проверка (17.10.2026)

Fixtures сгенерированы эталонным кодом в браузере (настоящий WebCrypto: AES-GCM, PBKDF2 600 000, Ed25519, ECDH P-256,
HKDF) и проверены второй, независимой реализацией на Python. Результат: **все проверки пройдены**, в том числе:
кошелёк открывается паролем и ключом провайдера и даёт тот же ключ данных; неверный пароль не открывает; 22 записи
расшифровываются, совпадают с открытой копией и проходят схему; стёртая запись - надгробие, цепочка цела; в файле
кошелька нет открытого текста; подмена одного байта даёт ровно одну ошибку цепочки; подписи квитанций, штампа,
решений, профиля и именного отзыва сходятся; обязывающее решение пришло от арбитра из мандата; v, проверки «на
ощущениях» и коэффициенты учёта плана пересчитаны одинаково; JCS-числа по RFC 8785.

Повторить: `python tools/verify_fixtures.py` (нужны `jsonschema`, `cryptography`).
